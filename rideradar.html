The Problem

Despite being the backbone of Surat's mobility, the BRTS Sitilink network operates with zero real-time visibility for passengers.

  • 87% of passengers face uncertain waits
  • 72% lack any schedule information
  • 58% have missed buses due to unknown delays
  • 44% switch to auto-rickshaws out of frustration

📡

Hardware

LilyGO T-SIM7000G GPS modules. Low-cost, cellular-enabled, and high-precision.

☁️

Backend

Node.js & Socket.io for real-time WebSocket communication and MQTT data ingestion.

🗺️

Mapping

Leaflet.js + OpenStreetMap. Eliminating costly API fees while maintaining performance.

📱

Client

Flutter mobile application and QR-code enabled web lite for instant access.
